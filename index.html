About: How to Use Translate & Summarize News

Flow 1: Extract → Translate → Summarize (Translated Text)

  • Upload a file (PDF, DOC, JPG, PNG)
  • Click Extract Text to process the content
  • Select a language from the dropdown
  • Click Translate
  • Check Use translated text for summarization
  • Click Summarize to generate summary in translated language
  • Optionally, click Download Summary

Flow 2: Extract → Summarize (Original Text)

  • Upload a file
  • Click Extract Text
  • Skip language selection & translation
  • Keep the checkbox unchecked
  • Click Summarize to summarize original content

Notes

  • Supported formats: PDF, DOC, DOCX, JPG, JPEG, PNG
  • Supports 30+ languages including Hindi, Marathi, Tamil, French, etc.
  • Uses AI4Bharat IndicBART for multilingual summarization
